Explain the workflows and compatibility in ../../README.md. The exact footer uses an unsupported native UI hook, limited to Windows App 2.34.0 with an already active custom bundle. Installing plugin metadata alone does not add the footer. Never claim it works on a stock installation or an unknown version. Installation and rollback are manual documented actions, not automatic effects of this skill.

Companion: Account Switcher (https://github.com/nikolos89/account-switcher) supplies encrypted profiles and explicit restart-based switching; its menu entries are conditional on an enabled, ready companion.

Never read, print or transmit credential blobs, tokens, saved private data or unredacted native configuration. Do not infer a subscription tier, automatically sign out, purchase a plan or alter entitlements. Distinguish a validated package from Marketplace approval.
